# The third-party software a download can carry, for scripts/third-party-notices.
#
# One line per component, fields separated by tabs:
#
#   id   name   home page   library files that are this component
#
# The id names the licence beside this file, <id>.txt, which is the licence as
# its authors wrote it, copied from the source the release builds from, and an
# optional <id>.note, which says where the component is in the download.
#
# The last field is shell patterns for the shared libraries that are this
# component, matched against the file name only, first line first: so a more
# specific name has to come before a pattern that would also take it (Tk
# before Tcl, opusfile before opus).  "-" means it is never a file of its own:
# it is compiled into something else, and a packager names it explicitly.
#
# A packager that scans its package with -s fails on any shared library that
# matches no line here.  Adding a library to a download means adding a line
# and its licence, not only copying the file.
