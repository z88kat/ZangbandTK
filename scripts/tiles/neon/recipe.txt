# recipe.txt -- where each Neon picture is in the design brief, and how to cut it.
#
# build-neon.py --cut reads this and the brief's sheets
# (archive/design_brief_tileset_neon/<sheet>/sheet.jpeg) and writes source.png
# and source.txt.  One line per picture:
#
#     <id> <sheet> <cell> [cut:<q>] [lift:<n>]
#
# cell counts 1 to 16, left to right then down.  Written from the brief's
# accepted.txt, where every picture taken from a returned sheet is listed, and
# the `importer:` notes in each sheet's cells.txt.
#
#   cut:q   set each pixel's brightness by the qth fraction of its block, not
#           the 75th percentile: for stripes and bands drawn grey on light,
#           which the 75th washes out.
#   lift:n  every grey n levels brighter: for a picture drawn in mid-grey,
#           which looks dim in every colour.  The rule from batch 13: lift
#           every monster with under 30% of its lit pixels bright (the two
#           top greys, or a colour's pale or neon), unless its notes say
#           otherwise.  Where a note says why, it follows the #.
#
# The 18 pictures not here (the walls, floors, bolts and burst) are drawn by
# build-neon.py itself.
