# manifest.txt -- which Neon picture each thing in the game is drawn with.
#
# Read by scripts/tiles/build-neon.py.  A picture is named by its id in the
# source atlas (source.txt), which is the id it had in the brief, or by the id
# of one the script draws itself (feat-floor, the walls, the bolts).  The list
# of pictures is the 1982 set's, and so is this file below the terrain:
# Neon was redrawn picture for picture.  Monsters are in monsters.txt.
#
# Every picture is coloured with the thing's own colour from lib/gamedata, so
# one potion bottle is every potion.  Anything not listed here and not covered
# by a `tval:` default has no tile and renders as its ASCII letter;
# audit-tiles.py reports it.

# --- terrain: feat:<CODE>:<picture>[:<ground>][:<glyph>][:tone=T][:quiet=N] ---
#
# <ground> is what shows through the black of the picture, in its own colour:
# the floor under the stairs and rubble, the town's grass under the buildings.
# <glyph> is the number or letter stamped on a building, as on the 1982 set's
# gables: the shop's glyph from terrain.txt, or for the services, whose glyph
# is +, the letter the owner chose for 1982 on 3 November 2026.  It goes on
# the shops' plain roof, right of the sign; at=X,Y puts its top left corner
# elsewhere.  The cottages were asked for a plain gable and a round window
# above the door, and the window took the gable, so their letter goes over
# the window; the towers' between the window and the door.
#
# tone=T is the tone the feature sits at in plain light, where the 16x16 set
# put it; without one it sits at its colour's own tone, or a tone down from
# pale, so a torch has somewhere brighter to take it.  quiet=N takes N tones
# off every grey and colour in the picture: water and lava at full strength
# drown what stands in them (pilot 2), and the sea, which nobody walks on,
# needs only one (batch 1).
