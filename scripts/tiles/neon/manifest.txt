# manifest.txt -- which silhouette each thing in the game is drawn with.
#
# One shape serves every creature that shares it, because colour is what
# separates them and colour comes from lib/gamedata.  Thirty-odd breeds of
# zephyr hound are one drawing here, and each is finally the colour its own
# entry in monster.txt claims it is.
#
# Anything not listed has no tile and renders as its ASCII letter.  That is
# the intended state of an unfinished set, and it is the same argument
# scripts/tiles/README makes about uniques: a letter says "not drawn yet".

# --- terrain: feat:<CODE>:<shape>[:<tone when lit>] ---
#
# The fourth field names the tone a feature sits at when lit; the light moves
# it from there.  Without one it sits at the tone its colour code maps to.
#
# Ground and walls all want `dim`: they are the backdrop, and whatever stands
# on them has to win.  They are named individually because they start from
# four different base tones -- Angband's colours were picked for single glyphs
# and FLOOR is White while GRANITE is Light Slate.
#
# An absolute tone and not a relative shift.  Relative was tried and was wrong
# twice: the shifts stacked with the lighting offset and clamped, so all four
# ground features landed on `shadow` together -- black, at actual size -- and
# the global darkening step aimed at the walls pushed lava and broken doors
# off the bottom with them.---------------------------------------
