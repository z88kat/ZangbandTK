T	h3	How do I avoid the “Couldn’t load the requested X11 font (10x20)” message?
T	h3	\n
T	p0	The X11 frontend requires 
T	p0 em	legacy bitmap fonts
T	p0	. Many modern systems no longer install those fonts by default, or install them in locations that X11 does not search automatically.
T	p0	\n
T	p0	Common ways to resolve this include:
T	p0	\n
T	li1	•\t
T	li1	Install legacy X11 bitmap font packages provided by your operating system (package names vary by distribution).
T	li1	\n
T	li1	•\t
T	li1	Explicitly select an installed bitmap font by setting the 
T	li1 code	ANGBAND_X11_FONT
T	li1	 environment variable.
T	li1	\n
T	li1	•\t
T	li1	Use a different front end (SDL2, Windows, macOS) that does not rely on X11 bitmap fonts.
T	li1	\n
T	p0	On Linux, the required font is typically provided as 
T	p0 code	10x20.pcf.gz
T	p0	. If your distribution allows searching packages by installed files, look for a package that provides that file. Common examples include:
T	p0	\n
T	li1	•\t
T	li1	Debian/Ubuntu and derivatives: 
T	li1 code	xfonts-base
T	li1	\n
T	li1	•\t
T	li1	Red Hat–derived distributions: 
T	li1 code	xorg-x11-fonts-misc
T	li1	\n
T	li1	•\t
T	li1	Arch Linux: 
T	li1 code	xorg-fonts-misc
T	li1	\n
T	p0	Depending on the distribution and configuration, installing these packages may not be sufficient if X11 is not configured to search the installed font paths.
T	p0	\n
T	p0	If none of the above works, please check the forums for distribution-specific advice, or open an issue including your OS, distribution, and ZangbandTK version.
T	p0	\n
M	is-there-a-way-to-disable-that-thing-that-pops-up-when-you-hit-the-enter-key
T	h3	Is there a way to disable that thing that pops up when you hit the enter key?
T	h3	\n
T	p0	Go into the options menu, choose “Edit keymaps”, then “Create a keymap”. Press Enter at the “Key” prompt and a single space as the “Action”.
T	p0	\n
T	p0	And then you’ll probably want to choose to “Save keymaps to a file”, and either choose the file name so that it is one automatically loaded when a character is loaded or combine the contents of the saved file with one of the automatically loaded preference files. That allows the change to stay in effect the next time you load the game.
T	p0	\n
T	p0	This just replaces the default action of Enter with a “do nothing but don’t tell me about help” action. If you want to keep the menu available, say on the ‘Tab’ key, you can also remap the Tab keypress to the 
T	p0 code	\\n
T	p0	 action.
