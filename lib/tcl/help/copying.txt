T	p0 note strong	Note
T	p0 note	\n
T	p0 note strong	The tilesets shipped with this game have been changed.
T	p0 note	 None of them was drawn for ZangbandTK, so none had art for the wilderness, and the imported bestiary rendered as ASCII letters among the pictures.
T	p0 note	\n
T	p0 note	Two kinds of change, and the difference decides whether a licence forbidding modification has been respected. A 
T	p0 note strong	mapping
T	p0 note	 adds a 
T	p0 note code	.prf
T	p0 note	 file pointing at art already in the sheet and alters no image. A 
T	p0 note strong	modification
T	p0 note	 writes pixels into it.
T	p0 note	\n
T	li1 note	•\t
T	li1 note strong	Gervais’ 32x32 has one row added
T	li1 note	: four service buildings it had no art for, and the Statue and Figurine Stores’ doors, all drawn by a script. Everything above that row is Angband’s sheet, pixel for pixel, and thirteen terrain features point at cells Angband never used.
T	li1 note	\n
T	li1 note	•\t
T	li1 note strong	Adam Bolt’s, Nomad’s and the original 8x8 are modified
T	li1 note	: two rows of generated tiles, terrain and service buildings, are appended to the bottom of each. Adam Bolt’s also gains three rows of the tiles Bolt drew for Zangband (sixty-five uniques, the magical figurine and ten statues), and the 8x8 gains one row of Zangband’s own figurine and statues. Nothing already in those sheets is touched: every original cell keeps its coordinates and every original pixel its value. The generated tiles take their colours from the sheet being extended, so they are in that tileset’s own palette.
T	li1 note	\n
T	li1 note	•\t
T	li1 note strong	All four gain ``.prf`` files
T	li1 note	, which are mappings and change no art.
