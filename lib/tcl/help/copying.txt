T	p0 note strong	Note
T	p0 note	\n
T	p0 note strong	The tilesets shipped with this game have been changed.
T	p0 note	 None of them was drawn for ZangbandTK, so none had art for the wilderness, and the imported bestiary rendered as ASCII letters among the pictures.
T	p0 note	\n
T	p0 note	Two kinds of change, and the difference decides whether a licence forbidding modification has been respected. A 
T	p0 note strong	mapping
T	p0 note	 adds a 
T	p0 note code	.prf
T	p0 note	 file pointing at art already in the sheet and alters no image. A 
T	p0 note strong	modification
T	p0 note	 writes pixels into it.
T	p0 note	\n
T	li1 note	•\t
T	li1 note strong	Gervais’ 32x32 is mapped only
T	li1 note	 — the image is byte-identical to Angband’s. Thirteen terrain features point at cells Angband never used.
T	li1 note	\n
T	li1 note	•\t
T	li1 note strong	Adam Bolt’s, Nomad’s and the original 8x8 are modified
T	li1 note	: one row of thirty generated terrain tiles is appended to the bottom of each. Nothing already in those sheets is touched — every original cell keeps its coordinates and every original pixel its value — and the colours are sampled from the sheet being extended, so the additions are in that tileset’s own palette.

T	li1 note	•\t
