# File: p_race.txt


# This file is used to initialize the player race information for Angband.

# Do not modify this file unless you know exactly what you are doing,
# unless you wish to risk possible system crashes and broken savefiles.

# === Understanding p_race.txt ===

# Format:
# name:race name
# stats:str:int:wis:dex:con
# skill-disarm:base
# skill-device:base
# skill-save:base
# skill-stealth:base
# skill-search:base
# skill-melee:base
# skill-shoot:base
# skill-throw:base
# skill-dig:base
# hitdie:hitdie
# exp:expbase
# infravision:infra
# history:history
# age:agebase:agemod
# height:hgt:modhgt
# weight:wgt:modwgt
# obj-flags:object flags
# player-flags:player flags
# values:values
# light:radius
# armour:base:scale
# gain-at:level
# gain-obj-flags:object flags
# gain-values:values
# equip-instead:replaced tval:tval:sval:min:max
# virtues:virtues
# mutation-affinity:mutation:weight
# mutation-rate:one-in
# power:name  (then power-level, power-cost, power-stat, power-fail,
#              power-effect, power-dice, power-expr, power-when)

# 'name' indicates the beginning of an entry.

# 'stats' is for the stat modifiers - strength, intelligence, wisdom,
# dexterity, constitution.

# 'skill-<skill name>' is for skills that get added at birth - physical
# and magical disarming, magic devices, saving throws, stealth,
# to hit (normal), to hit (bows), to hit (throwing), digging.

# 'hitdie' is for max. hitpoints gained per level.

# 'exp' is for percent of "standard" experience needed to gain a level.

# 'infravision' is for range of infravision in multiples of 10 feet.

# 'history' is for starting point of the player history (see history.txt).

# 'age' is age info - base age, random age modifier.

# 'height' is height info - base height, random height modifier.

# 'weight' is weight info - base weight, random weight modifier.

# 'obj-flags' is for object flags (as in src/list-obj-flags.h) that
# races possess innately.

# 'player-flags' is for player flags (as in src/list-player-flags.h) that
# races possess innately.

# 'values' is for object modifiers which take a value that races possess
# innately.

# 'light' is a light radius the race carries itself, with no lamp -- a
# Vampire's own dim glow.  Added to whatever equipment provides.

# 'armour' is innate armour class: a flat amount, plus character level
# divided by the scale.  'armour:20:5' is a Golem, which is 20 points of
# hardened clay at birth and 30 by level 50.  A scale of 0 means no level
# term.

# 'gain-at' opens a band of properties the race grows into rather than being
# born with, and applies to every 'gain-obj-flags' and 'gain-values' line
# following it until the next 'gain-at'.  The level is inclusive: 'gain-at:15'
# arrives at level 15.  Zangband grants most racial properties this way -- a
# Draconian resists fire at 5, cold at 10, acid at 15, lightning at 20 and
# poison at 35 -- and a gained property is indistinguishable from an innate
# one once it arrives.

# 'equip-instead' is a starting-kit substitution: the race takes this object
# in place of whatever its class would have given of the replaced tval.  A
# Vampire takes scrolls of Darkness instead of torches, because it carries its
# own light and what it needs is a way to put the sun out.  The grant does not
# depend on the class having had anything to replace -- a Vampire Necromancer
# starts with no light at all and still gets its scrolls.

# 'virtues' is for the virtues a race inclines towards (see virtue.txt).

# 'mutation-affinity' weights a race towards one mutation; 'mutation-rate' is
# the one-in-N chance of gaining one on gaining a level (Beastmen).

# 'power' begins a racial power -- something the race can do that no class
# teaches -- and is followed by its level, cost, stat, failure rate and
# effect, in the same shape as a class spell.

# ---------------------------------------------------------------------------
# ZangbandTK's races (PLR-01)
#
# Zangband kept its races in C rather than a data file, so these are ported by
# hand from tables.c and files.c.  Nine of its twenty-one, curated rather than
# imported wholesale: several of the rest are close variants of races already
# here, and four are undead wanting a mechanism 4.2 has not got.
#
# How the numbers were arrived at, since it is not a straight copy.  Ten races
# appear in both games, so the mapping could be measured rather than guessed:
#
#   stats, hit dice           identical in 8 of 10.  Copied.
#   disarm, device, save,     identical in 7 to 9 of 10.  Copied.
#   stealth
#   search                    differs with no pattern -- 4.2 redesigned it race
#                             by race.  Copied, as good an anchor as any.
#   melee, shoot              4.2 widened the spread, by roughly double.  So
#                             doubled here.
#   experience                4.2 flattened nearly every race to 120; Zangband
#                             ranged 100 to 255 and used it as its balance dial.
#                             Kept, which is what makes a Half-Titan expensive.
#
# Charisma is dropped: Zangband has six stats and 4.2 has five.
# ---------------------------------------------------------------------------

# A vampire carries its own dim light in the archive (TR_LITE, files.c:1469),
# which was missed -- so the one race that is hurt by light also had none of
# its own.  Everything here is granted at birth: the Vampire is the one
# imported race with no level thresholds at all.
#
# SLOW_DIGEST was here and is not in the archive.  It was the wrong sign twice
# over: a benefit, on the race whose relationship with food is that food does
# not work.  Zangband gives it a tenth of a meal instead (cmd6.c:99), which is
# what BLOOD_DIET now does.  UNDEAD starts it just after midnight, so the sun
# is not already up on a race the sun burns.
obj-flags:HOLD_LIFE
player-flags:BLOOD_DIET | UNDEAD
values:RES_DARK[3] | RES_NETHER[1] | RES_POIS[1] | RES_COLD[1] | RES_LIGHT[-1]

# Zangband packs a Vampire differently before it looks at the class at all
