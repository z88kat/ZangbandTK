# File: rename.txt
#
# Things this game used to call something else.
#
# A savefile records what it holds by *name* -- "prayer book",
# "[Novice's Handbook]", "raving lunatic" -- and not by number, so a character
# saved before a rename names something the game can no longer find. Without
# this file the object is simply lost, which is survivable but not free: the
# character wakes up short of it (see rd_item() in load.c).
#
# This file is how a rename costs nothing instead. Each line says what the old
# name became, and the loader consults it when a lookup fails. It is only read
# on the failing path, so it costs nothing at all for a current savefile.
#
# **Add an entry whenever you rename or remove something a savefile can hold.**
# That is objects, monsters, artifacts and ego types. It takes one line and it
# is the difference between a character keeping its sword and not.
#
# object:<tval>:<old sval>:<new sval>
#   An object kind. The tval is the current one; if the tval changed too, the
#   old name is unreachable and the object is lost -- rename svals, not tvals.
#
# monster:<old name>:<new name>
# artifact:<old name>:<new name>
# ego:<old name>:<new name>
#
# A `new` name of "-" means the thing was removed outright rather than renamed.
# That is not the same as leaving it out: it records that the loss is known and
# intended, so the next reader does not go looking for a mistake.


# === The Life realm (DEC-50, 3.60.0) =====================================
#
# Zangband's four prayer books replaced Angband's five. Two of the old five
# were town books and appeared in every savefile in existence, because every
# save carries the town temple's stock. Mapped by what the book is for rather
# than by position: the beginner's book to the beginner's book, and the rest
# to the nearest rung of the new ladder.

object:prayer book:[Novice's Handbook]:[Book of Common Prayer]
object:prayer book:[Cleansing Power]:[High Mass]
object:prayer book:[Healing and Sanctuary]:[Book of the Unicorn]
object:prayer book:[Battle Blessings]:[Book of the Unicorn]
object:prayer book:[Wrath of the Valar]:[Blessings of the Grail]

# === Two monsters that were Angband's all along =============================
#
# Not dropped: deduplicated. Zangband's `hobo` and `raving lunatic` are
# Angband's boil-covered wretch and village idiot under different names --
# identical in glyph, colour, speed, armour, depth and experience, and both
# still in Angband under the older name. The import kept Angband's names, which
# is why a savefile written before that names something that is not there.
#
# They point at the monster they always were rather than at nothing, so a
# character's kill record survives the deduplication.

monster:hobo:boil-covered wretch
monster:raving lunatic:village idiot
