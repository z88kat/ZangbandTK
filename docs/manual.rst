==========
The Manual
==========

The reference manual: character creation, the dungeon, combat, and the full
command and option lists.

These chapters come from Angband, which ZangbandTK is built on, and they
describe the mechanics the two games share. Where a chapter here and a page
under :doc:`What's Different <differences>` disagree, go with the page: those
were written for this game, and these were adapted to it.

All seven were checked against the game as it is now, and the parts that
described Angband instead of this game were fixed: the endgame, the map
symbols, the keysets, the command and option lists, the file paths and the
front ends. They have *not* been rewritten. The prose, the examples and the
emphasis are still Angband's, and these chapters don't try to explain the
wilderness, the towns, pets, mutations, patrons or the realms. Those have pages
of their own.

:doc:`birth` has changed the most. It has the full race and class tables for
all twenty-eight races and fourteen classes, and its sections on racial powers,
martial arts, psionics and patrons are this game's own.
