==========
The Manual
==========

The reference manual: character creation, the dungeon, combat, and the full
command and option lists.

These chapters are inherited from Angband, which ZangbandTK is built on, and
they describe the mechanics the two games share. Most have not yet been revised
for ZangbandTK, so where a chapter here and a page under
:doc:`What's Different <differences>` disagree, the latter is correct.

The exceptions are :doc:`birth`, which carries the full race and class tables
and has been brought up to date, and :doc:`command` and :doc:`option`, which
list every command and option the game actually has.
